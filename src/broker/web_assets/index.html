Broker 配置

编辑当前 Broker 使用的配置文件。保存后，Broker 设置需重启 Broker 生效；executor 设置只影响使用此文件的本机 executor，需重启该 executor。命令行参数及 BROKER_KEY 环境变量优先于文件。

修改 Key 后，请同步更新客户端和 executor 凭据；当前连接使用原 Key，直到 Broker 重启。Paseo 通知绑定仍在 executor 的「Paseo 通知」面板即时管理。

接入 MCP 客户端

生成此 Broker 的连接配置，在运行客户端的机器上添加。请先安装相应客户端，并确保该机器能访问以下地址。

默认使用当前站点的 /mcp；使用代理或隧道时，请填写客户端实际能访问的完整地址。远程访问请使用 HTTPS 或加密隧道。

默认引用 BROKER_KEY，请在启动客户端或执行添加命令前安全设置该环境变量。包含 Key 的内容仅用于私有配置，请勿提交到共享仓库。
